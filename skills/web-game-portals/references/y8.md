# Y8

Official: https://docs.y8.com/sdk/intro/ (SDK), https://developer.y8.com (developer portal). Notes from a hands-on integration and upload. Re-read the docs before relying on any detail.

## SDK (Minimal SDK v2.0)

- Script in `<head>`: `https://cdn.y8.com/minimal-sdk/2-0/y8.min.js` (async). When it is ready it fires `y8sdk.ready` on `window`; if it was ready first, `y8.emitReadyEvent()` fires it again.
- `const sdk = y8.sdk(); sdk.init({ appId, autoLogin: true }, { gameId, preloadAdBreaks: 'on', sound: 'on', onReady })`.
- **Two ids from the developer portal: an App ID and a Game ID.** Create the app there first; put both in `src/platform/config.js`. The adapter refuses to start without them.
- Ads: `sdk.showAd({ type: 'next', name, beforeAd, afterAd, adBreakDone })` for an interstitial between levels; `sdk.showAd({ type: 'reward', name, beforeReward(showAdFn), adViewed, adDismissed, adBreakDone })` for a rewarded ad. Grant the reward only when `adViewed` fired; `adBreakDone` always ends the break.
- Account: `sdk.onAuth((user, error) => ...)`.

The adapter (`templates/platform/y8.js`) and the `<head>` block (`templates/platform/vite.js`) implement this. Y8 has no fake SDK in `web-game-qa` yet: test in Y8's own preview before submitting.

## Submission

- Register a studio on the developer portal, create the game, upload a **zip** of the `dist-y8` build (`package.sh y8`), submit for moderation.
- Media the form asked for: screenshot 760x570, widescreen screenshot 1280x720, landscape promo 1920x1080, portrait promo 1080x1920, game card 760x570, and a gameplay video (a continuous 1080p clip of 15-20 s works; `web-game-trailer`).
- Y8 can also be reached by email for licensing (`developers@y8.com`).
